# Sparkle SFX

Use this folder for shimmer and glimmer sounds:

- ranked sprite glimmer marks
- extra sparkly glow accents
- tier reveal shimmer

These should stay light and layered, not overpower narration.

Current files:

- `major-con-siren-buzzer.mp3` - buzzer accent for major con siren VFX
- `major-pro-sparkle-shine.mp3` - chime accent for major pro sparkle VFX
- `micron-100-firework-lead-pop.mp3` - lead pop for 100% vitamin/mineral firework
- `micron-100-firework-cluster.mp3` - firework cluster for 100% vitamin/mineral firework
