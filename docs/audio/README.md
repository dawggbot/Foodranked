# Docs Audio

This folder contains audio files that GitHub Pages can load directly.

Generated narration mirrors live in:

```text
docs/audio/episodes/<food-id>/
```

Reusable SFX that need browser preview should be mirrored from `audio/sfx/` into:

```text
docs/audio/sfx/
```

The top-level source folder for reusable audio is `audio/`.
