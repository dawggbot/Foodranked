
## 2026-06-21 05:47 UTC - Macro display and arrow rules

- Durable FoodRanked display rule from James: arrow indicator directions should stay constant throughout all food types so uneducated viewers are not confused. Example decision: `starch_g` is visually higher-is-better consistently, including kale/carbs, rather than reversing by food type.
- Durable FoodRanked macro display rule from James: if a main macro has a numerical display and is not `N/A`, then every submacro under it must also display a numerical value, including `0g`; submacros may display `N/A` only when the parent main macro displays `N/A`.
- Recent pushed fix: commit `925e911` (`Fix macro submetric display and stable arrows`) enforces stable starch arrows, numeric submacro display under numeric parents, preserves bacon/meat carb `N/A` behavior, fixes protein section population, and keeps non-essential amino acids displayed as `/11`.
- Earlier pushed fix in same thread: commit `7027cb3` (`Fix zero macro N/A display and amino denominator`) made main macro `0g` display as `N/A`, set submacros to `N/A` when parent macro is `N/A`, preserved bacon/meat carb handling, fixed non-essential amino denominator to `/11`, and fixed dashboard/app missing-submacro fallback to avoid turning missing data into `0`.
