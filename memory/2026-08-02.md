- VBv2 MP4 macro bar fill SFX was fixed and pushed in commit `4349caf5` (`Fix VBv2 macro fill SFX export`). Root cause: VBv2 requested about `5.226x` playback speed for the macro fill sound, but the MP4 mixer clamped SFX tempo to `2x`, making the effect effectively wrong/inaudible. The exporter now uses chained ffmpeg tempo filters, keeps the correct source slice/fade timing, and bumps macro fill level to be audible. An 8-second Bacon MP4 smoke render measured the macro-fill window around `-12.6 dB`. Windows release: `studio-windows-v0.1.16-20260802`, `https://github.com/dawggbot/Foodranked/releases/download/studio-windows-v0.1.16-20260802/FoodRanked-Studio-Windows.zip`.
